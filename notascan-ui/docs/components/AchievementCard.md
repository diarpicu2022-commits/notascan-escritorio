# AchievementCard

Medalla de logro. Estados: **Desbloqueado** (medalla `gold`), **En progreso** (medalla discontinua `sage` + barra), **Bloqueado** (escala de grises, candado, borde discontinuo y menos énfasis, pero texto legible) y **Listo para reclamar** (brillo suave).

Props: `a: { name, state, icon, progress, goal }` · `onClick`.
