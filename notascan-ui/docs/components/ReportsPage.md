# ReportsPage

Consultar, exportar y revisar. Formato en chips (PDF · Excel · CSV), curso y periodo en selects; tres tipos de reporte como bloques de color (`navy` consolidado por curso, `sage` por estudiante, `gold` por evaluación) con "Generar", y una tabla de reportes recientes con descarga. El toast confirma cada generación. Solo se reportan notas verificadas.
