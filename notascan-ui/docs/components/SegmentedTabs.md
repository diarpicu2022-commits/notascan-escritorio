# SegmentedTabs

Pestañas segmentadas en píldora (`role="tablist"`). La activa se invierte a `navy` con conteo en `gold`. Flechas izquierda/derecha cambian de pestaña.

Props: `tabs: [{ value, label, icon?, count? }]` · `value` · `onChange` · `label`.

Navegación local dentro de una página (Grados/Cursos/Materias, estados de solicitudes, filtros móviles).
