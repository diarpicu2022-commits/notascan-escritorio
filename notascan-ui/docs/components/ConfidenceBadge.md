# ConfidenceBadge

`Badge` + nivel calculado a partir del porcentaje: "● Confianza IA 98%". El tono sale de `confidenceLevel()` y el nivel en palabras se anuncia a lectores de pantalla.

Props: `value` (0–100) · `compact` (texto "IA 98%", para la cabecera de `StudentGradeCard`).

Solo habla de la IA. Nunca escribas "Verificada" en un ConfidenceBadge.
