# Divider

Separador reutilizable.

- `hairline` (por defecto) — 1px `hairline`. Entre filas y bloques de una misma tarjeta.
- `strong` — 2px `navy`. Cierra una estructura (encima de la barra de filtros, pie de tarjeta).
- `ornament` — línea con rombo dorado y etiqueta en `overline` (`label`). Solo para separar secciones editoriales grandes, como en la página Design System. Máximo uno por pantalla.
