# GlobalSearch

Búsqueda global de estudiantes en la barra superior de Secretaría, Rectoría y Docente. Se abre con **Ctrl + K** (o ⌘K). Busca por nombre, ID estudiantil, documento o curso; muestra búsquedas recientes y atajos por curso; ↑↓ para moverse, Enter para abrir el perfil. La vista previa del estudiante da acceso inmediato a Perfil, Calificaciones, Historial académico, Asistencia, Observador y Boletines.

Props: `onOpenStudent(student, tab)`.
