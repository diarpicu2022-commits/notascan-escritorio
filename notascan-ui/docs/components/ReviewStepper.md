# ReviewStepper

El flujo completo de calificación en siete pasos: Cargar fotografía → Detectar estudiante → Detectar calificación → Calcular confianza → **Revisar** → Confirmar → Guardar. Los pasos hechos se rellenan de `navy` con check; el actual es un disco `gold` con `shadow-sm` y `aria-current="step"`.

Props: `current` (1–7) · `steps` (sustituye las etiquetas).

En pantallas < 720px se vuelve vertical.
