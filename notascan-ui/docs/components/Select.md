# Select

Lista desplegable nativa con la misma piel que `Input`: label real, `*` de obligatorio en `burgundy`, ayuda, error y foco con barra `gold`.

Props: `label` · `options` (texto o `{ value, label }`) · `value` / `defaultValue` · `onChange(value)` · `placeholder` · `required` · `hint` · `error` · `disabled`.
