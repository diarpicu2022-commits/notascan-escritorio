# ReportCardManager

Gestor de boletines: filtros por grado, curso, periodo y estado; tabla con Pendiente / Generado / Bloqueado por paz y salvo; acciones Previsualizar (abre el `ReportCardDocument` en un modal de documento) y Generar PDF; en lote, Generar selección; y Generar todos (con confirmación, omite bloqueados).
