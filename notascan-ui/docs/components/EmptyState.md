# EmptyState

Estados vacíos y de error con personalidad editorial y sin ilustraciones de stock: un sello circular con icono y anillo punteado `gold-ink`, título en `display` y una sola acción.

- **Vacío** — borde discontinuo `navy` sobre `paper`. "No hay calificaciones pendientes. Carga una evaluación para comenzar la revisión."
- **Error** (`tone: "error"`) — `burgundy` sobre `burgundy-soft`. "No pudimos detectar una calificación. Puedes introducirla manualmente."

Props: `title` · `message` · `action` · `icon` · `tone`.

Nunca mostrar mensajes técnicos (códigos, excepciones) al docente.
