# EvaluationsPage

Exámenes, talleres y actividades. Tabs locales por tipo; un bloque `gold-soft` muestra el porcentaje asignado y su reparto en segmentos (examen `navy`, taller `gold`, actividad `sage-soft`). Cada evaluación es una tarjeta con cabecera por tipo, sticker, estado, el porcentaje en una baldosa grande, avance de verificación y la acción que corresponde (Revisar / Calificar / Ver).
