# StudentTable

Tabla de Estudiantes y Matrículas sobre `DataGrid`: avatar, nombre completo, documento, ID estudiantil, grado, curso, acudiente, estado (Activo, Pendiente, Retirado, Archivado con icono y palabra) y fecha de matrícula. Búsqueda, filtros por curso y estado, selección con acciones en lote (Exportar, Generar boletines, Archivar) y acciones por fila (Ver perfil, Editar, Archivar, Retirar) con confirmación. Ver y Editar abren un `Drawer`.

Props: `readOnly` (Rectoría) · `onNavigate`.
