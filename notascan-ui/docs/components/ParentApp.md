# ParentApp

Aplicación móvil del acudiente (diseño para Flutter), separada de la del estudiante y sin gamificación: hijo/a seleccionado, avisos importantes, resumen de promedio, asistencia y comportamiento, calificaciones recientes, calendario de asistencia, observador, boletines como documento y notificaciones.

Props: `page` (`home` · `grades` · `attendance` · `observer` · `reportcards` · `notifications`) · `onNavigate` · `onLogout`.
