# Switch

Interruptor accesible (`role="switch"`, `aria-checked`). La perilla muestra ✓ o × y, con `onText`/`offText`, el estado se escribe en palabras: nunca depende solo del verde/burdeos.

Props: `checked` · `onChange(v)` · `label` · `ariaLabel` · `onText` · `offText` · `disabled` · `hideLabel`.

Úsalo para estados binarios que se guardan al instante (Paz y Salvos, trabajar sin conexión).
