# NotaScanApp

La aplicación completa con enrutador por hash: `#/login` → `#/dashboard` → `#/grade` → `#/review` → `#/students` · `#/evaluations` · `#/reports` · `#/system`. El sidebar navega entre páginas y "Cerrar sesión" vuelve al login.

Props: `initial` (ruta inicial; si se omite, lee el hash).
