# Toast

Aviso breve tras una acción importante. Superficie sólida `paper`, borde y sombra brutalista, disco de icono por tono (`success` `sage`, `error` `burgundy`, `info` `gold`).

Props: `tone` · `title` · `message` · `onClose`. `role="status"` (o `alert` en errores). Se muestra abajo a la derecha dentro de `.ns-toast-region` y desaparece a los ~4s.

Para errores de validación usa feedback inline, no toasts.
